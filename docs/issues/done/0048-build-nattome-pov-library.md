Labels: needs-triage
Type: AFK

## Parent

## What to build

Build the Nattome POV Library as the editable home for Nattome's owned brand-safe interpretations, messaging territories, product/campaign/market targeting, and adaptation rules. The POV Library must remain distinct from the Pattern Library, which captures external TikTok mechanics.

## Acceptance criteria

- [ ] Marketers can create, edit, approve, and archive Nattome POV entries.
- [ ] POV entries support title, description, brand-safe interpretation, adaptation rules, product, campaign, market, language, audience/avatar, symptom/occasion, channel, status, and source links.
- [ ] POV entries can link to Approved Patterns.
- [ ] Defaults can assume Nattome, Malaysia, and mixed/English language where appropriate.
- [ ] POV edits preserve version history with attribution and timestamps.
- [ ] The UI explains the distinction between external patterns and Nattome POVs through structure and labels.
- [ ] Tests cover create/edit/archive flows, pattern links, targeting fields, defaults, and version history.
