# Add Recommended Shoot Timed Scripts

Labels: needs-triage
Type: AFK

## Parent

`docs/prd/top5-creative-production-report-prd.md`

## What To Build

Extend the Top 5 Creative Production Report so each creative brief marks exactly one Recommended Shoot and renders a production-ready timed script for that Recommended Shoot only.

Each Recommended Shoot should include a one-sentence recommendation reason, a separate Hook line, and a script table with `Time`, `Scene`, `On-screen text`, and `Exact line` columns. Scripts should default to 20-35 seconds unless the source format clearly needs longer, use natural Malaysian retail-friendly English, and avoid hard-coded product mention, product appearance, CTA, or soft close rules.

## Acceptance Criteria

- [ ] Each creative brief marks exactly one Recommended Shoot.
- [ ] Each Recommended Shoot includes a one-sentence "Recommended because" reason.
- [ ] Each Recommended Shoot includes a separate Hook line.
- [ ] Only the Recommended Shoot includes a full script.
- [ ] Alternate angles remain in the compact concept table without full scripts.
- [ ] Each full script uses a table with Time, Scene, On-screen text, and Exact line columns.
- [ ] Each timed script includes short on-screen text for every segment.
- [ ] Script scene labels remain simple and do not become detailed B-roll notes.
- [ ] Recommended scripts default to 20-35 seconds unless the source format clearly requires longer.
- [ ] Script lines use natural Malaysian retail-friendly English.
- [ ] Script lines avoid overly medical language.
- [ ] Script lines avoid overly Gen Z language.
- [ ] Product mentions are concept-specific rather than mandatory.
- [ ] Product appearance is concept-specific rather than mandatory.
- [ ] CTA usage is concept-specific rather than mandatory.
- [ ] Soft closes are allowed when a CTA would feel forced.
- [ ] Tests prove only the Recommended Shoot receives a full script.
- [ ] Tests cover a CTA ending and a soft-close ending.
