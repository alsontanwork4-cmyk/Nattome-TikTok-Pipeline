# Generate Cross-Video Pattern Summary And Priority Scores

Type: AFK

## Parent

`docs/prd/nattome-tiktok-ocr-video-evidence-pipeline-prd.md`

## What To Build

Generate a batch-level Cross-Video Pattern Summary that compares Video Evidence Reports and ranks patterns and Shootable Angles using Nattome Priority Score.

## Acceptance Criteria

- [ ] Each Batch Analysis Run produces one Cross-Video Pattern Summary.
- [ ] The summary compares hooks, formats, emotional triggers, audio patterns, risky claims, and Nattome opportunities.
- [ ] The summary identifies top priority Shootable Angles.
- [ ] Nattome Priority Score includes viral strength, Nattome relevance, evidence confidence, brand safety, ease of production, and product fit.
- [ ] Nattome Priority Score totals out of 30 points.
- [ ] The summary recommends what to shoot first and why.
