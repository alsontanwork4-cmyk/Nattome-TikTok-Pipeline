# Use Gemini Evidence-First Video Analysis Tool Stack

The TikTok batch pipeline will use evidence-first analysis: source videos, Gemini timestamped visual evidence, visible text, spoken content, audio cues, claim evidence, audio/music review, and metadata must feed the creative report. The default tool stack is Apify for TikTok discovery/download, Gemini 2.5 Flash for source-video evidence extraction, and markdown, JSON, and CSV outputs. This is still heavier than metadata-only analysis, but it removes local video/OCR/transcription executables while preventing unsupported claims about hooks, pacing, subtitles, and on-screen content.
