# Use Batch Evidence Reports For TikTok OCR Analysis

Nattome TikTok analysis will run as batch-first evidence capture rather than metadata-only reporting or one-off OCR. Each batch selects videos through minimum filters and viral relevance ranking, then creates one Evidence Bundle and Video Evidence Report per video, plus a Cross-Video Pattern Summary and required markdown, JSON, and spreadsheet outputs. This is slower than metadata-only analysis, but it supports the real goal: finding repeatable creative patterns from what viewers actually see and hear.
